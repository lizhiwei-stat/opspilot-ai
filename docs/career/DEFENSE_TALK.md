# 项目答辩讲稿（约 8–10 分钟）

各位好，我介绍个人作品 **OpsPilot AI**：一个面向技术支持场景的智能运维 Agent 平台。

**问题**：支持同学要在文档、日志、错误码和工单系统之间反复跳转，既慢也容易越权或误开单。

**做法**：我用 LangGraph 把防护、分类、MCP 工具、证据评估、生成与校验串成图；需要建单时 **interrupt**，管理员审批后从 **Postgres 检查点**恢复，由 Ticket MCP 落正式工单。知识库有 ACL；工具在 MCP 子进程中执行并审计。

**体验**：React 管理台覆盖工作台 SSE、工单审批、授权与可观测性。默认 Mock，付费模型多重开关。

**证据**：仓库内有可追溯评测——RAG Mock hybrid R@5=0.946；Agent v1 回归 45 条成功率 100%；扩展冻结集 87.1%。安全与负载有自动化报告。我做过从零 Compose 验证与备份恢复演示。

**取舍**：不做 K8s/Redis/Grafana，是为了把复杂度花在 Agent 正确性与工程可复现上（ADR-005）。

**局限**：Mock 不能代表真实大模型；扩展集仍有失败；未公网部署。

谢谢，欢迎提问。
