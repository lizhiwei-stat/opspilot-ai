# 支付网关对接说明

## 第 1 页：接口概览
订单服务通过 HTTPS 调用支付网关的 /v2/charge 接口完成扣款，请求必须携带商户号和签名。默认超时时间为 3 秒，超时后返回 ERR_PAY_TIMEOUT。支付网关的状态页地址在内部 Wiki 的"支付网关"条目中。

## 第 2 页：回调与签名
支付结果通过异步回调通知订单服务。回调请求使用 HMAC-SHA256 签名，密钥每 90 天轮换一次。如果密钥轮换后订单服务没有同步更新，回调会签名校验失败，订单服务返回 ORD-5004，订单停留在"待支付"状态。

## 第 3 页：熔断与降级
订单服务对支付网关启用熔断器：10 秒内失败率超过 50% 时打开，30 秒后进入半开状态探测。熔断打开期间，新订单进入"支付确认中"状态，由后台任务异步确认，避免用户请求长时间阻塞。
