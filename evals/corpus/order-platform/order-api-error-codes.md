# 订单 API 错误码说明

本文列出订单服务对外返回的业务错误码。所有错误响应格式为 {"code": "...", "message": "...", "trace_id": "..."}。

## 4xx 客户端错误

| 错误码 | HTTP 状态 | 含义 | 处理建议 |
|---|---|---|---|
| ORD-4001 | 400 | 请求参数缺失或格式错误 | 检查必填字段 sku_id、quantity |
| ORD-4002 | 400 | 库存不足 | 提示用户减少购买数量 |
| ORD-4003 | 409 | 重复下单（幂等键冲突） | 同一个 Idempotency-Key 在 24 小时内只能使用一次 |
| ORD-4010 | 401 | 访问令牌无效或过期 | 重新获取访问令牌 |
| ORD-4030 | 403 | 无权操作该订单 | 确认订单归属 |
| ORD-4290 | 429 | 请求过于频繁 | 遵守 Retry-After 响应头 |

## 5xx 服务端错误

| 错误码 | HTTP 状态 | 含义 | 处理建议 |
|---|---|---|---|
| ORD-5001 | 500 | 未知内部错误 | 携带 trace_id 联系订单平台组 |
| ORD-5002 | 500 | 订单状态机异常，状态流转非法 | 检查订单当前状态，勿重复提交 |
| ORD-5003 | 503 | 数据库连接池耗尽 | 稍后重试；值班人员按排查手册扩容 |
| ORD-5004 | 500 | 支付回调签名校验失败 | 检查支付网关密钥是否轮换 |
| ERR_PAY_TIMEOUT | 500/503 | 调用支付网关超时（默认超时 3 秒） | 客户端可在 30 秒后重试，最多 3 次 |

## 重试建议

只有 5xx 和 429 可以重试。重试必须携带相同的 Idempotency-Key，避免重复扣款。建议使用指数退避：1 秒、2 秒、4 秒。
